# 项目计划：从 Beta 0.5.1 到参赛提交

> 面向「安全与应急创新」赛项 · 四川省减灾中心企业命题
> 时间列按比赛截止日期倒推填写，本文用"第 N 周"表示相对节奏。

## 一、现状基线

平台主体已跑通，本计划从这里起步，不包含已完成的部分：

| 能力 | 状态 |
| --- | --- |
| 五模块流水线（导入清洗 → 多维分析 → 可视化 → 报告生成） | 已跑通 |
| 智能体层：7 个工具 + 状态机 + 结果校验 | 已完成 |
| 10 张标准图表，含分级着色图与空间热力图 | 已完成 |
| 报告导出 Word / PDF / Markdown | 已完成 |
| Web 界面：7 个选项卡、会话历史、主题切换 | 已完成 |
| 端到端自检 9 项 | 全过 |
| 一键启动器 / 打包脚本 / 离线可运行 | 已完成 |

**当前版本 Beta 0.5.1。** 剩余工作集中在三处：真实数据对接、数据质量闭环、呈现与答辩。

## 二、项目目标

1. **逐条满足赛项四条硬性要求**，且每条都能现场演示、能举证
2. **换成组委会真实数据后一键跑通**，字段比对报告不留"未识别列"
3. **交付三件套**：可运行系统 + 技术方案书 + 答辩演示

## 三、里程碑

| 阶段 | 时间 | 目标 | 完成标准 | 主责 |
| --- | --- | --- | --- | --- |
| **M1 数据对接** | 第 1 周 | 吃透组委会的模板与数据 | 字段比对报告"未识别列"为空；真实数据能跑完全流程 | A |
| **M2 质量闭环** | 第 2 周 | 补齐数据质量能力 | 跨字段勾稽校验上线；数据质量评分卡可出图 | A + B |
| **M3 呈现打磨** | 第 3 周 | 报告与界面达到可展示水准 | 报告有目录与图表编号；问答准备 5 个演示问题 | B + C |
| **M4 冻结演练** | 第 4 周 | 功能冻结，演练答辩 | 演示脚本走通 3 次；备用录屏完成 | 全体 |
| **M5 提交** | 截止前 3 天 | 材料齐备并留出缓冲 | 方案书、源码包、演示视频全部提交 | 全体 |

**为什么 M1 必须最先做**：整条链路依赖真实字段。模板没对齐，后面所有打磨都是在沙子上盖楼。

## 四、任务清单

### A —— 数据与治理（关键路径，压力最大）

| # | 任务 | 依赖 | 完成标准 |
| --- | --- | --- | --- |
| A1 | 真实模板字段映射（改 `config/schema.json` 的 `aliases`） | 拿到组委会模板 | 比对报告无未识别列、无缺失必需字段 |
| A2 | 行政区划参照表全量化（替换演示用的最小集） | 无 | 县级名称比对覆盖全部区县 |
| A3 | 跨字段勾稽校验（新增 `config/validation_rules.json`） | A1 | 死亡+失踪 ≤ 受灾人口、绝收 ≤ 受灾、分项损失之和 ≤ 直接经济损失 |
| A4 | 数据质量评分卡（完整率 / 一致率 / 规范率 / 重复率） | A3 | 报告附录第一页出分项得分与总分 |
| A5 | 与组委会确认数据口径 | 对外沟通 | 形成一页口径说明，写进方案书 |

### 共担

- 方案书：各写自己那一章，**队长统稿**
- 演示脚本：C 主笔，A / B 补充各自环节的看点
- 答辩 PPT：每人 3–5 页，讲自己的模块

## 五、关键路径与风险

**关键路径：组委会模板 → 字段映射 → 全链路跑通 → 报告可导出 → 演示可复现。**
这条链上任何一环断了，其它工作都无法验收。

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 组委会数据迟迟不到 | 全链路无法验证 | 先用模拟数据把流程跑通；数据到位后只改配置不改代码 |
| 现场没有网络 | 大模型问答不可用 | 平台已支持离线规则模型，演示准备两套说辞 |
| 演示机器缺依赖装不上 | 平台起不来 | 用 `打包Beta.bat` 出源码包；提前在演示机上完整跑一遍 |
| 三人改动互相冲突 | 合并困难、进度停滞 | 文件边界 + develop 分支 + 每日三句话同步 |
| 时间不够 | 功能做不完 | 任务已按优先级排列，砍到 M2 仍可完整演示 |

## 六、最小可交付

如果只剩一周：**只做 A1 + A3 + C3**。

真实数据能跑通、数据质量有校验、演示脚本能背下来——这三样保证答辩不崩，其余都可以在答辩里说成"下一步计划"。

## 七、每阶段结束时的自查

对着赛项要求逐条问一遍：这条要求，**我现在能不能当场演示出来？**

- Excel 批量上传 →
- 字段与模板完全匹配 →
- 缺失值填充 / 异常值识别 / 格式统一 / 层级关系校验 →
- 分灾种 / 分时段 / 分区域 / 损失结构 / 自定义维度（≥2）→
- 趋势 / 对比 / 占比 / 空间分布 / 自定义图表（≥1）→
- 报告自动生成 + Word / PDF 导出 →

任一条答不上来，就是下一阶段的最高优先级。
